# Electron modernization history

> **Archived:** this file preserves the broad milestones of the early Electron modernization. Its branch, worktree, open-task, and acceptance instructions are obsolete and must not be used as current status.

The project moved from Electron remote APIs to Electron 28 with context isolation, a preload IPC allowlist, sandboxing, and system packaging. Historical implementation detail remains available in Git history.
