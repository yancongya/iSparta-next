## 1. 工具链完整性校验 + 可信安装（展开）

**投入**：小到中。优先做"哈希校验 + 失败重装"，staging 原子切换次之。

**落地要点**：
- 为每类编码器建清单（路径、SHA256、期望大小、白名单）。
- 启动或首次使用时校验，不通过则从内置副本恢复。
- CEP 与桌面共用一份清单，避免两端漂移。
- 只读资源不直接执行；校验通过后再落可执行位。
- staging 目录 + `ready.json` marker 保证原子切换、断点可恢复。

## 2. 目标大小前置规划（展开）

**投入**：中。需要先有一版"目标体积 → 起始质量"的估算模型，用实际样本校准。

**落地要点**：
- 估算精度要求不高，宁可保守（估低一点，让 `sizeGate` 兜底）。
- 与现有 `sizeGate.js`、`quality-retry-sliders` 的 `maxTries` 语义保持一致。
- 结果作为起始建议，不替换事后重试——两者并存更稳。
- 首压前按目标体积估算起始质量，减少重试次数与大动画耗时。
