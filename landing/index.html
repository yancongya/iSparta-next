00 · ABOUT

iSparta-next 是什么？iSparta 停更后的现代替代

iSparta-next（官网本页）是一款开源、跨平台的桌面动图转换工具，在长期停止维护的经典 iSparta 基础上重构，面向需要处理 PNG 序列、APNG、Animated WebP、GIF 的设计师与前端开发者。 与旧版相比，iSparta-next 升级到 Electron 28，重做了工作台 UI，并加入输出大小阈值、路径变量模板、批量导入与前后对比等能力。

格式互转

支持 PNG 序列合成 APNG / GIF / Animated WebP，以及 APNG、GIF、WebP 之间的互转与再压缩，适合表情包、贴纸与帧动画导出。

体积可控

输出大小阈值可在超出上限时自动按步长降质量重压，适配平台 1MB 等体积限制，减少手动反复试压缩。

批量与路径

拖拽 / 粘贴导入多组帧目录；路径变量模板与源目录输出策略，便于按项目批量导出与归档。

系统与下载

Windows / macOS / Linux 免费使用。安装包由 GitHub Actions 构建，可在 GitHub Releases 获取最新版；亦可从本页下载区选择对应平台。

一个安装包，按需勾选

同一个安装包里，桌面版与 AE 扩展可单独勾选、也可一并安装；安装范围支持所有用户或仅当前用户。

两端同一颗引擎

桌面端与 AE 扩展共用同一套压缩 / 合成 / 降质算法，输出的大小规则与命名习惯完全一致。

    06 · AFTER EFFECTS

    同步支持 CEP 端一步安装！

    iSparta-next 深度嵌入 AE，基于 CEP 重新定制前后端，打开面板就自动识别全部合成，直接导出成动图，全程不用离开 AE。

    刷新即识别，直接出片

    面板开着就自动同步工程里的合成，嵌套的子合成也一并列出；勾选即可导出 APNG / WebP / GIF，不必回到桌面端。

    两种视图，随意切换

    任务列表与合成树视图一键切换，双击合成即可在 AE 里直接定位它，管理一整个工程也不费劲。

    变量输出路径，归档不乱

    输出目录支持 {comp}、{fmt} 等变量模板，按合成名与格式自动分文件夹，批量导出后依然条理清晰。

    为 CEP 小屏重新排版

    不是把桌面界面硬塞进窄面板：控件、字号与间距都按 CEP 面板宽度重新适配，窄窗口一样完整可用。

    开发热更新，改完即生效

    面板与主程序都接上开发服务器：改代码自动热替换，CEP 面板不用重装、不用重启 AE，迭代调试快得多。

    CEP 端能力对齐桌面版

    扩展面板不是附庸品：任务列表、设置、命名、日志一应俱全，桌面端有的能力这里都能用到。

    贴合 AE 工作流

    从工程面板到导出都在 AE 里完成，省去在文件夹与软件之间来回切换，节奏不被打断。

    两端同源，产出一致

    与桌面端共用同一套压缩 / 合成 / 降质算法，输出的大小规则与命名习惯完全一致，跨端协作不返工。

    选中合成 → 变量路径落盘 → APNG / WebP / GIF

    运行时

    界面

    自研工作台

    两栏任务列表、亮暗主题、前后对比；不再绑定 Element UI。

    导出

    自动压小 · 存放随心 · 命名可控

    大小超限自动降质量重压；保存位置和文件名都由你拼。

    批量

    任务流水线

    多选、粘贴导入、全局默认设置、四态进度与批量开始。

    依赖

    发版

    三端 CI

    GitHub Actions 构建 Win / macOS / Linux，自动版本与 Release Notes。

    扩展

    CEP 面板同步重做

    After Effects 面板复用同一套组件与设计令牌，不是另做一套缩水界面。

    开发

    热更新开发链路

    桌面与 CEP 面板都接开发服务器，改代码即时生效，免去反复重装重启。

    10 · LINEAGE

    从原版到 iSparta-next

    感谢原作者与每一位社区维护者。本仓库站在他们肩膀上继续改。

    1. 原版 · 长期停更

      iSparta / iSparta

      经典 APNG / WebP 桌面转换工具。Electron 与依赖停在旧线，大量历史 Issue 无人跟进，安全补丁跟不上——这是 fork 浪潮的起点。

    2. 社区 fork

      Xheldon / iSparta

      修复帧乱序等问题，部分界面修补，证明「还能继续维护」。

    3. 基建 fork · 本仓库直接上游

      bigxixi / iSparta

      libwebp 1.5（修 CVE-2023-4863）、Electron 6→13、Vue CLI 4、execFile 防注入、存储/转换锁修复、迁到 GitHub Actions。

    4. 当前 · iSparta-next

      yancongya / iSparta-next

      在 bigxixi 基建上再次 fork：Electron 28 + sandbox / IPC，弃用 Element UI 重做工作台，新增大小阈值、路径变量、拆字命名、前后对比等；三端 CI 发版。
