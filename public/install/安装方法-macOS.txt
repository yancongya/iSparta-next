iSparta-next · AE 扩展安装方法（macOS）

官网 / 下载 / 更新：https://yancongya.github.io/iSparta-next/


1.拷贝 io.github.isparta-next 文件夹到以下位置:
~/Library/Application Support/Adobe/CEP/extensions/
（路径不存在就先建：mkdir -p ~/Library/"Application Support"/Adobe/CEP/extensions）

2.双击解压出来的 安装扩展.command（和本说明在同一层）即自动写入 PlayerDebugMode=1（AE 才能加载未签名扩展）
若提示「无法打开 / 身份不明」：右键该文件 → 打开 → 打开；
或在终端 cd 到解压目录后执行：bash install-as-admin

3.打开AE软件设置，勾选上「允许脚本写入文件和访问网络」
Mac：After Effects-首选项-脚本和表达式

4.重启AE后，在软件顶部 window 窗口菜单-扩展下即可看到 iSparta-next


常见问题：菜单里没出现扩展？
- 首选项勾选是否做了、install-as-admin 是否运行成功
- 文件夹是否直接位于 extensions\ 下（没多套一层）
- 是否重启过 AE（改配置和文件都必须重启）

支持：After Effects 15.0（CC 2015）～最新 · macOS 11+（Apple Silicon / Intel）
