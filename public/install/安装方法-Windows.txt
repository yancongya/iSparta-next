  iSparta-next · AE 扩展（Windows）安装说明
════════════════════════════════════════════════════════════════════

本包内容
  io.github.isparta-next\        ← 扩展主体（把它整个文件夹放进 extensions\）
  安装方法-Windows.txt            ← 本文件
  Add Keys.reg                    ← 一键开启 CEP 调试模式（双击运行）
  version.json                    ← 版本清单（桌面版用它判断是否需要刷新扩展）

  ⚠ 本包**只是 AE 扩展**，不含桌面应用。
     需要桌面应用请下载安装包（一次装全：桌面 + 扩展）：
     https://github.com/yancongya/iSparta-next/releases


────────────────────────────────────────────────────────────────────
  方式一：桌面版安装包（推荐）
────────────────────────────────────────────────────────────────────

  Windows 安装包是**一体安装**：组件页里同时勾选「桌面应用」和
  「After Effects 扩展」，一次装完、版本一致，之后还能在应用内自动更新。

  安装范围只问一次（安装向导的「安装模式」页）：
    · 所有用户  → 扩展落到 Common Files，需要管理员权限
    · 仅当前用户 → 扩展落到 %APPDATA%，无需管理员
  两者互斥，不会重复写两份。

  ⚠ 安装程序**不会重启 AE**。装完请手动重启一次 After Effects。


────────────────────────────────────────────────────────────────────
  方式二：手动安装（本包）
────────────────────────────────────────────────────────────────────

  1. 解压，得到 io.github.isparta-next 文件夹

  2. 双击运行「Add Keys.reg」
     在「用户账户控制」弹窗里选「是」，允许修改注册表。
     这一步给 Adobe CSXS 写入 PlayerDebugMode=1，是 CEP 扩展能被
     AE 加载的前提。

  3. 把 io.github.isparta-next 文件夹复制到下面**其中一个**目录：

       用户级（无需管理员，推荐）
         %APPDATA%\Adobe\CEP\extensions\
         实际路径类似：C:\Users\<你的用户名>\AppData\Roaming\Adobe\CEP\extensions\

       系统级（需要管理员权限）
         %CommonProgramFiles%\Adobe\CEP\extensions\
         实际路径类似：C:\Program Files\Common Files\Adobe\CEP\extensions\

     extensions 目录不存在就手动建一个。
     ⚠ 不要两个位置都放 —— AE 只加载其中一个，放两份会造成版本混乱。

  4. 打开 AE → 编辑 → 首选项 → 脚本和表达式
     勾选「允许脚本写入文件和访问网络」

  5. 重启 After Effects

  6. 菜单栏 → 窗口 → 扩展 → 选择 iSparta-next <版本号>


────────────────────────────────────────────────────────────────────
  卸载
────────────────────────────────────────────────────────────────────

  1. 删除扩展文件夹（二选一，删你当初放的那个）：
       %APPDATA%\Adobe\CEP\extensions\io.github.isparta-next
       %CommonProgramFiles%\Adobe\CEP\extensions\io.github.isparta-next

  2. 调试模式可以保留，不影响 AE；如需还原，在注册表编辑器里删除
     HKEY_CURRENT_USER\Software\Adobe\CSXS.* 下新建的 PlayerDebugMode 值。


────────────────────────────────────────────────────────────────────
  常见问题
────────────────────────────────────────────────────────────────────

  Q：窗口 → 扩展 菜单里找不到 iSparta-next？
  A：按顺序排查
     ① 「允许脚本写入文件和访问网络」是否已勾选（编辑 → 首选项 → 脚本和表达式）
     ② Add Keys.reg 是否真的执行成功（注册表里应有 CSXS.*\PlayerDebugMode=1）
     ③ 扩展文件夹是否**直接**位于 extensions\ 下（不要多套一层目录）
     ④ 是否**重启过** AE（改完注册表和文件都必须重启才生效）

  Q：面板能打开但找不到合成 / 转换失败？
  A：面板需要 Node 环境（AE 2019+ 自带）。若 AE 版本较老请升级；
     另外确认工程的合成时长、帧率正常（面板直接从合成读取渲染参数）。

  Q：更新扩展后没变化？
  A：扩展是整目录替换的，若装在 Common Files 下请确认写权限；
     也可能是 AE 未完全退出（后台进程仍在），用任务管理器结束
     AfterFX.exe 再启动。

  支持系统：Windows 10 / 11（x64）
