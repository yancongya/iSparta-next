iSparta-next · AE 扩展安装方法（Windows）

官网 / 下载 / 更新：https://yancongya.github.io/iSparta-next/

推荐：运行官网下载的 Windows .exe；安装时会申请管理员权限，检测到 After Effects 后自动部署桌面版与本扩展。以下步骤仅供单独下载 CEP 压缩包时手动安装。


1.拷贝 io.github.isparta-next 文件夹到以下位置:
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

2.运行一下解压出来的 Add Keys.reg（和本说明在同一层，写入 PlayerDebugMode=1，AE 才能加载未签名扩展）

3.打开AE软件设置，勾选上「允许脚本写入文件和访问网络」
Win：编辑-首选项-脚本和表达式

4.重启AE后，在软件顶部 window 窗口菜单-扩展下即可看到 iSparta-next


常见问题：菜单里没出现扩展？
- 首选项勾选是否做了、Add Keys.reg 是否运行成功
- 文件夹是否直接位于 extensions\ 下（没多套一层）
- 是否重启过 AE（改注册表和文件都必须重启）

支持：After Effects 15.0（CC 2015）～最新 · Windows 10/11 x64
